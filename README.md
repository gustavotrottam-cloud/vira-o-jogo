# Vira o jogo · O seu caso

Página de celular da palestra "Vira o jogo" (Gustavo Trotta, CFP®), publicada pelo GitHub Pages em `https://gustavotrottam-cloud.github.io/vira-o-jogo/`.

- `index.html`: o caso de cada um em seis passos (o placar do mês, as dívidas, o consignado, os frangos, o goleiro e o 13º, e o jogo longo com a Selic de hoje), o plano em imagem e a semana de treinos. Não pede nome nem telefone. Desde 06/11/2026, os números do caso vão, sem identificação e arredondados, para uma planilha (Apps Script) que alimenta o painel; quem marca "Não quero entrar na conta do grupo" não manda nada.
- `resultados.html`: o painel com a conta do grupo. Só mostra dados com a chave, que não fica neste repositório; `resultados.html#demo` mostra dados de exemplo, inventados.

A versão de trabalho fica na pasta do evento, em `Calculadora\placar.html`. Para atualizar: copie o arquivo para `index.html` aqui, faça o commit e o push.
