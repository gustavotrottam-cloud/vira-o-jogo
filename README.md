# Vira o jogo · Calculadora do placar

Página de celular com as três contas da palestra "Vira o jogo" (Gustavo Trotta, CFP®): o placar do mês, o gol contra e o jogo longo. Publicada pelo GitHub Pages.

A versão de trabalho fica na pasta do evento, em `Calculadora\placar.html`. Para atualizar: copie o arquivo para `index.html` aqui, faça o commit e o push.
